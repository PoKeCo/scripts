# Scripts Collection

This repository is a personal collection of utility scripts designed to automate various tasks on a Linux environment.

## Overview

The scripts are organized into several directories based on their functionality:

-   **`git/`**: Contains scripts for automating git workflows, such as version bumping and branch management.
-   **`image2txt/`**: A set of scripts for converting images (specifically PPM format) to text.
-   **`ros/`**: Scripts related to the Robot Operating System (ROS), like component monitoring and automatic decompression.
-   **`sandbox/`**: A place for experimental or miscellaneous scripts.
-   **`ui/`**: Scripts for controlling UI elements, such as enabling or disabling a touchpad.
-   **`util/`**: General utility scripts.

## Usage

Each script is intended to be run from the command line. For specific usage instructions, please refer to the comments or help functions within each script file.

# スクリプト集

このリポジトリは、Linux環境における様々なタスクを自動化するために設計された、個人用のユーティリティスクリプト集です。

## 概要

スクリプトは、その機能に基づいていくつかのディレクトリに分類されています。

-   **`git/`**: バージョン管理の更新やブランチ管理など、Gitのワークフローを自動化するスクリプトが含まれています。
-   **`image2txt/`**: 画像（特にPPM形式）をテキストに変換するための一連のスクリプトです。
-   **`ros/`**: Robot Operating System (ROS) に関連するスクリプトで、コンポーネントの監視や自動解凍などを行います。
-   **`sandbox/`**: 実験用またはその他の雑多なスクリプトを配置する場所です。
-   **`ui/`**: タッチパッドの有効化/無効化など、UI要素を制御するためのスクリプトです。
-   **`util/`**: 一般的なユーティリティスクリプトです。

## 使用方法

各スクリプトはコマンドラインからの実行を想定しています。具体的な使用方法については、各スクリプトファイル内のコメントやヘルプ機能をご参照ください。
